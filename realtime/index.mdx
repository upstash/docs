Upstash Realtime adds realtime features to Next.js projects. It is HTTP-based, built on Redis streams and server-sent events, with type-safe events, message history, and built-in authentication helpers.

## Pages

- [Quickstart](/realtime/overall/quickstart): set up Realtime in a Next.js app.
- [Client-Side Usage](/realtime/features/client-side): subscribe to events in React.
- [Server-Side Usage](/realtime/features/server-side): emit events, subscribe to channels, and read history on the server.
