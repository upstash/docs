---
title: HDEL
description: Deletes one or more hash fields.
---


## Arguments

<ParamField body="key"type="string" required>
  The key to get.
</ParamField>

<ParamField body="fields" required>
  One or more fields to delete.
</ParamField>

## Response

<ResponseField  type="integer" required>
    The number of fields that were removed from the hash.
</ResponseField>

<RequestExample>
```ts Example
await redis.hset("key", { field1: "a", field2: "b", field3: "c" });
await redis.hdel("key", "field1", "field2");
// returns 2
```
</RequestExample>
