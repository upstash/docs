An Express server connects to Upstash Redis with a standard Redis client. The
server reads one connection string from `REDIS_URL`, so the same code runs on
any host where you set that variable.

This quickstart adds a cache-aside route: it reads from Redis first, and on a
miss it loads the data, stores it with a TTL (time to live, after which Redis
deletes the key) and returns it.

<Note>
  On serverless and edge runtimes, use
  [`@upstash/redis`](/redis/howto/connect-with-upstash-redis) instead.
</Note>

### Database Setup

Create a Redis database using the [Upstash Console](https://console.upstash.com)
or [Upstash CLI](https://github.com/upstash/cli). Open the database page, go to
the **Connect** section and select the **TCP** tab. Copy the connection string.
It looks like this:

```text
rediss://default:YOUR_TOKEN@YOUR_ENDPOINT:6379
```

See [Connect Your Client](/redis/howto/connect-client) for what each part means.

### Project Setup

Create a project and install Express and ioredis:

```shell
mkdir express-upstash && cd express-upstash
npm init -y
npm install express ioredis
```

### The Code

Create `index.js`:

```javascript index.js
const express = require("express");
const { Redis } = require("ioredis");

const app = express();
const redis = new Redis(process.env.REDIS_URL);

// Stand-in for a slow database or third-party API
async function getProductFromDb(id) {
  await new Promise((resolve) => setTimeout(resolve, 500));
  return { id, name: `Product ${id}`, price: 19.99 };
}

app.get("/products/:id", async (req, res) => {
  const key = `product:${req.params.id}`;

  const cached = await redis.get(key);
  if (cached) {
    return res.json({ source: "cache", data: JSON.parse(cached) });
  }

  const product = await getProductFromDb(req.params.id);
  await redis.set(key, JSON.stringify(product), "EX", 60);
  res.json({ source: "database", data: product });
});

const port = process.env.PORT || 3000;
app.listen(port, () => {
  console.log(`Server running on port ${port}`);
});
```

The route caches each product for 60 seconds. When the data changes, delete the
key (`await redis.del(key)`) so the next request loads the new value.

### Run Locally

Put the connection string in a `.env` file and start the server. Node.js 20.6
and later can load the file with `--env-file`:

```shell .env
REDIS_URL="rediss://default:YOUR_TOKEN@YOUR_ENDPOINT:6379"
```

```shell
node --env-file=.env index.js
```

Request the same product twice. The first request loads it from the
"database", the second one comes from Redis:

```shell
curl http://localhost:3000/products/42
# {"source":"database","data":{"id":"42","name":"Product 42","price":19.99}}

curl http://localhost:3000/products/42
# {"source":"cache","data":{"id":"42","name":"Product 42","price":19.99}}
```

Add `.env` to your `.gitignore` so the token is not committed.

### Deploy

The app only needs two things from a host: a way to run `node index.js` and an
environment variable named `REDIS_URL` with your connection string. Hosts set
`PORT` themselves, and the code above already reads it.
