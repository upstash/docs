---
title: $standard
description: Run one query, and set its weight inside $rrf.
---

The `$standard` retriever runs one query. Use it inside [`$rrf`](./rrf) to set the weight of a query.

```json
{ "$standard": { "query": { "name": "headphones" }, "weight": 2 } }
```

### Parameters

| Parameter | Description | Default |
|---|---|---|
| `query` | Required. A query object. See [Queries](/redis/search/querying). | |
| `weight` | A number, `0` or greater. It scales how much the query adds to the `$rrf` score. Valid only inside `$rrf`. | `1` |

### Plain Query Objects

A plain query object works the same as `$standard` without a weight. Use `$standard` only when you need
to set a weight.

These two `$rrf` retrievers give the same results:

```json
{ "$rrf": { "retrievers": [{ "name": "headphones" }, { "description": "wireless" }] } }

{ "$rrf": { "retrievers": [{ "$standard": { "query": { "name": "headphones" } } }, { "$standard": { "query": { "description": "wireless" } } }] } }
```

### Examples

<Tabs>

<Tab title="Redis CLI">
```bash
# Give the name match twice the weight of the description match
SEARCH.QUERY products '{"$rrf": {"retrievers": [{"$standard": {"query": {"name": "headphones"}, "weight": 2}}, {"description": "headphones"}]}}'

# Same as SEARCH.QUERY products '{"name": "headphones"}'
SEARCH.QUERY products '{"$standard": {"query": {"name": "headphones"}}}'
```
</Tab>
