---
title: "SETRANGE"
description: "Overwrite part of string."
---

Use `SETRANGE` to overwrite part of the string stored at a key, starting at a byte offset.

The key is created when it does not exist, and if the offset lies past the current end of the value the string is first padded with zero bytes, so writing at a large offset allocates everything up to it. The reply is the length of the string after the write.

Together with [`GETRANGE`](/redis/commands/string/getrange) this makes it possible to treat a string as a fixed-layout record and update one field in place, without reading and rewriting the whole value.

## Syntax

```redis
SETRANGE <key> <offset> <value>
```

## Arguments

| Argument | Required | Repeatable | Description |
| --- | --- | --- | --- |
| `<key>` | Yes | No | Redis key targeted by the command. |
| `<offset>` | Yes | No | Zero-based byte offset to write at. The value is zero-padded if the key is shorter. |
| `<value>` | Yes | No | String written starting at the offset. |

## Response

The reply reports the result of the operation. Error replies have the same shape in RESP2 and RESP3 and are surfaced as exceptions by the SDKs below.

| Protocol | Reply |
| --- | --- |
| RESP2 | Integer |
| RESP3 | Integer |

<Note>
  Client libraries often decode bulk strings, maps, sets, and numeric strings into language-native values. The table describes the Redis wire reply.
</Note>

## Examples

TCP examples use the TLS `REDIS_URL` from the Upstash console. REST examples use `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN`.

<AccordionGroup>

<Accordion title="Redis CLI" defaultOpen>

```bash
SETRANGE my-key 0 value
```

</Accordion>

<Accordion title="@upstash/redis" icon="node-js" iconType="brands">

```ts
import { Redis } from "@upstash/redis";

const redis = Redis.fromEnv();

await redis.set("key", "helloworld")
const length = await redis.setrange("key", 5, "redis");
console.log(length); // 10

// The value of "key" is now "helloredis"
```

</Accordion>

<Accordion title="go-redis" icon="golang" iconType="brands">

```go
package main

import (
    "context"
    "fmt"
    "os"

    "github.com/redis/go-redis/v9"
)

func main() {
    opts, err := redis.ParseURL(os.Getenv("REDIS_URL"))
    if err != nil {
        panic(err)
    }
    client := redis.NewClient(opts)
    result, err := client.SetRange(context.Background(), "my-key", 0, "value").Result()
    if err != nil {
        panic(err)
    }
    fmt.Println(result)
}
```

</Accordion>

use redis::TypedCommands;

fn main() -> redis::RedisResult<()> {
