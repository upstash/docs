---
title: "SEARCH.ALIASADD"
description: "Create or update a search index alias."
---

Use `SEARCH.ALIASADD` to create an alias or update an existing alias to point to a search index.

See [Aliases](/redis/search/aliases#adding-an-alias) for feature examples, including zero-downtime index swaps.

The target name is not required to exist when the alias is created, so aliases can temporarily be dangling. Most commands resolve aliases, but [`SEARCH.DROP`](/redis/commands/search/search-drop) always uses a literal index name.

## Syntax

```redis
SEARCH.ALIASADD <alias> <index_name>
```

## Response

Returns `1` if a new alias was created or `2` if an existing alias was updated, including when it already points to the supplied index.

});
