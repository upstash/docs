---
title: "ARGET"
description: "Get the value at an array index."
---

Use `ARGET` to read the value stored at a single array index.

The reply is null when the slot is empty and when the key does not exist at all, so a missing array and a hole inside an existing one look the same. Use [`ARCOUNT`](/redis/commands/array/arcount) or [`EXISTS`](/redis/commands/generic/exists) when the difference matters. To read many slots at once, [`ARMGET`](/redis/commands/array/armget) takes a list of indexes and [`ARGETRANGE`](/redis/commands/array/argetrange) takes a range.

See the [array command overview](/redis/commands/array/overview) for the data model these commands share.

## Syntax

```redis
ARGET <key> <index>
```

## Arguments

| Argument | Required | Repeatable | Description |
| --- | --- | --- | --- |
| `<key>` | Yes | No | Array key targeted by the command. |
| `<index>` | Yes | No | Zero-based index to read. Must be between `0` and `18446744073709551614`. |

## Response

The reply reports the result of the operation. Error replies have the same shape in RESP2 and RESP3 and are surfaced as exceptions by the SDKs below.

| Protocol | Reply |
| --- | --- |
| RESP2 | Bulk string or Null bulk string or null array |
| RESP3 | Bulk string or Null |

<Note>
  Client libraries often decode bulk strings, maps, sets, and numeric strings into language-native values. The table describes the Redis wire reply.
</Note>

TCP examples use the TLS `REDIS_URL` from the Upstash console. REST examples use `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN`.

<Accordion title="go-redis" icon="golang" iconType="brands">

```go
package main

import (
    "context"
    "fmt"
    "os"

    "github.com/redis/go-redis/v9"
)

func main() {
    opts, err := redis.ParseURL(os.Getenv("REDIS_URL"))
    if err != nil {
        panic(err)
    }
    client := redis.NewClient(opts)
    result, err := client.ARGet(context.Background(), "my-array", 0).Result()
    if err != nil {
        panic(err)
    }
    fmt.Println(result)
}
```

<Accordion title="redis-rs" icon="rust" iconType="brands">

```rust
fn main() -> redis::RedisResult<()> {
    let url = std::env::var("REDIS_URL").expect("REDIS_URL is not set");
    let client = redis::Client::open(url)?;
    let mut connection = client.get_connection()?;

    let mut command = redis::cmd("ARGET");
    command.arg("my-array");
    command.arg("0");
    let result: redis::Value = command.query(&mut connection)?;
    println!("{result:?}");
    Ok(())
}
```
