---
title: "ZRANDMEMBER"
description: "Get random members."
---

Use `ZRANDMEMBER` to get random members of a sorted set without removing them.

Without a count one member is returned, or null when the key does not exist. A positive count returns up to that many distinct members, capped at the size of the set, while a negative count returns exactly that many members chosen independently, so repeats are possible. `WITHSCORES` returns each member together with its score.

Use it for sampling and random selection, and [`ZPOPMIN`](/redis/commands/sorted-set/zpopmin) or [`ZPOPMAX`](/redis/commands/sorted-set/zpopmax) when members should be consumed.

## Syntax

```redis
ZRANDMEMBER <key> [<count> [WITHSCORES]]
```

## Arguments

| Argument | Required | Repeatable | Description |
| --- | --- | --- | --- |
| `<key>` | Yes | No | Redis key targeted by the command. |
| `<count> [WITHSCORES]` | No | No | Number of members to return; a negative count may repeat members. `WITHSCORES` also returns each member's score. |

## Important points

- RESP2 represents floating-point reply values as bulk strings; RESP3 may use native double replies. Client libraries commonly decode either form to a language number.

## Response

The reply reports the result of the operation. Error replies have the same shape in RESP2 and RESP3 and are surfaced as exceptions by the SDKs below.

| Protocol | Reply |
| --- | --- |
| RESP2 | Null bulk string or null array, Bulk string, array of members, or flat member/score array |
| RESP3 | Null, Bulk string, array of members, or array of member/score pairs |

<Note>
  Client libraries often decode bulk strings, maps, sets, and numeric strings into language-native values. The table describes the Redis wire reply.
</Note>

TCP examples use the TLS `REDIS_URL` from the Upstash console. REST examples use `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN`.

<Accordion title="go-redis" icon="golang" iconType="brands">

```go
package main

import (
    "context"
    "fmt"
    "os"

    "github.com/redis/go-redis/v9"
)

func main() {
    opts, err := redis.ParseURL(os.Getenv("REDIS_URL"))
    if err != nil {
        panic(err)
    }
    client := redis.NewClient(opts)
    result, err := client.ZRandMember(context.Background(), "my-key", 1).Result()
    if err != nil {
        panic(err)
    }
    fmt.Println(result)
}
```

use redis::TypedCommands;

fn main() -> redis::RedisResult<()> {
