---
title: "ZINTERCARD"
description: "Get intersection cardinality."
---

Use `ZINTERCARD` to get the number of members that the given sorted sets have in common, without building the intersection.

`<numkeys>` states how many keys follow. `LIMIT` stops the count once that many common members are found and returns the limit, which answers "do these sets overlap by at least N" far more cheaply than a full intersection; `LIMIT 0` means no limit. Only the count is computed and returned, so nothing is stored and no scores are transferred.

## Syntax

```redis
ZINTERCARD <numkeys> <key> [<key> ...] [LIMIT <limit>]
```

## Arguments

| Argument | Required | Repeatable | Description |
| --- | --- | --- | --- |
| `<numkeys>` | Yes | No | Number of key arguments that follow. |
| `<key>` | Yes | Yes | Redis key targeted by the command. |
| `LIMIT <limit>` | No | No | Stop counting once this many members match; `0` means no limit. |

## Response

The reply reports the result of the operation. Error replies have the same shape in RESP2 and RESP3 and are surfaced as exceptions by the SDKs below.

| Protocol | Reply |
| --- | --- |
| RESP2 | Integer |
| RESP3 | Integer |

<Note>
  Client libraries often decode bulk strings, maps, sets, and numeric strings into language-native values. The table describes the Redis wire reply.
</Note>

TCP examples use the TLS `REDIS_URL` from the Upstash console. REST examples use `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN`.

<Accordion title="go-redis" icon="golang" iconType="brands">

```go
package main

import (
    "context"
    "fmt"
    "os"

    "github.com/redis/go-redis/v9"
)

func main() {
    opts, err := redis.ParseURL(os.Getenv("REDIS_URL"))
    if err != nil {
        panic(err)
    }
    client := redis.NewClient(opts)
    result, err := client.ZInterCard(context.Background(), 0, "my-key").Result()
    if err != nil {
        panic(err)
    }
    fmt.Println(result)
}
```

<Accordion title="redis-rs" icon="rust" iconType="brands">

```rust
fn main() -> redis::RedisResult<()> {
    let url = std::env::var("REDIS_URL").expect("REDIS_URL is not set");
    let client = redis::Client::open(url)?;
    let mut connection = client.get_connection()?;

    let mut command = redis::cmd("ZINTERCARD");
    command.arg("1");
    command.arg("my-key");
    let result: redis::Value = command.query(&mut connection)?;
    println!("{result:?}");
    Ok(())
}
```
