---
title: "VECTOR.DEL"
description: "Remove a vector from an index."
---

Use `VECTOR.DEL` to remove the vector stored under an ID.

The reply is `1` when the ID was present and `0` when it was not, so the call is safe to repeat. Removing the last vector does not delete the index: it stays in place, ready for new writes, until [`VECTOR.DROP`](/redis/commands/vector/vector-drop) removes it.

Vector indexes are an Upstash extension. See the [vector command overview](/redis/commands/vector/overview) for how an index is created, written to, and queried.

## Syntax

```redis
VECTOR.DEL <index> <id>
```

## Arguments

| Argument | Required | Repeatable | Description |
| --- | --- | --- | --- |
| `<index>` | Yes | No | Key holding the vector index. |
| `<id>` | Yes | No | Identifier to remove. Cannot be empty. |

## Important points

- An index that does not exist returns `ERR Index <index> is not found`.

## Response

The reply reports the result of the operation. Error replies have the same shape in RESP2 and RESP3 and are surfaced as exceptions by the SDKs below.

| Protocol | Reply |
| --- | --- |
| RESP2 | Integer: `1` if the ID was removed, `0` if it was not in the index |
| RESP3 | Integer: `1` if the ID was removed, `0` if it was not in the index |

<Note>
  Client libraries often decode bulk strings, maps, sets, and numeric strings into language-native values. The table describes the Redis wire reply.
</Note>

TCP examples use the TLS `REDIS_URL` from the Upstash console. REST examples use `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN`.

<Accordion title="go-redis" icon="golang" iconType="brands">

```go
package main

import (
    "context"
    "fmt"
    "os"

    "github.com/redis/go-redis/v9"
)

func main() {
    opts, err := redis.ParseURL(os.Getenv("REDIS_URL"))
    if err != nil {
        panic(err)
    }
    client := redis.NewClient(opts)
    result, err := client.Do(context.Background(), "VECTOR.DEL", "my-index", "doc:1").Result()
    if err != nil {
        panic(err)
    }
    fmt.Println(result)
}
```

```rust
fn main() -> redis::RedisResult<()> {
    let url = std::env::var("REDIS_URL").expect("REDIS_URL is not set");
    let client = redis::Client::open(url)?;
    let mut connection = client.get_connection()?;

    let mut command = redis::cmd("VECTOR.DEL");
    command.arg("my-index");
    command.arg("doc:1");
    let result: redis::Value = command.query(&mut connection)?;
    println!("{result:?}");
    Ok(())
}
```
