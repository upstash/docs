---
title: "VECTOR.DROP"
description: "Delete a vector index."
---

Use `VECTOR.DROP` to delete a vector index and every vector in it.

The reply is `1` when an index was removed and `0` when the key held nothing, so the call is safe to repeat. Since an index occupies an ordinary key, [`DEL`](/redis/commands/generic/del) and [`UNLINK`](/redis/commands/generic/unlink) remove it too; `VECTOR.DROP` is the form that says what is being removed and refuses to touch a key holding another type.

Vector indexes are an Upstash extension. See the [vector command overview](/redis/commands/vector/overview) for how an index is created, written to, and queried.

## Syntax

```redis
VECTOR.DROP <index>
```

## Arguments

| Argument | Required | Repeatable | Description |
| --- | --- | --- | --- |
| `<index>` | Yes | No | Key holding the vector index. |

## Important points

- Dropping an index that does not exist replies `0` rather than raising an error.
- A key holding a value that is not a vector index returns `WRONGTYPE`.

## Response

The reply reports the result of the operation. Error replies have the same shape in RESP2 and RESP3 and are surfaced as exceptions by the SDKs below.

| Protocol | Reply |
| --- | --- |
| RESP2 | Integer: `1` if the index was dropped, `0` if it did not exist |
| RESP3 | Integer: `1` if the index was dropped, `0` if it did not exist |

<Note>
  Client libraries often decode bulk strings, maps, sets, and numeric strings into language-native values. The table describes the Redis wire reply.
</Note>

<Accordion title="go-redis" icon="golang" iconType="brands">

```go
package main

import (
    "context"
    "fmt"
    "os"

    "github.com/redis/go-redis/v9"
)

func main() {
    opts, err := redis.ParseURL(os.Getenv("REDIS_URL"))
    if err != nil {
        panic(err)
    }
    client := redis.NewClient(opts)
    result, err := client.Do(context.Background(), "VECTOR.DROP", "my-index").Result()
    if err != nil {
        panic(err)
    }
    fmt.Println(result)
}
```

fn main() -> redis::RedisResult<()> {
