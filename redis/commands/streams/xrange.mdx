---
title: "XRANGE"
description: "Get range of stream entries."
---

Use `XRANGE` to read the entries of a stream within a range of IDs, from the oldest to the newest.

`-` and `+` stand for the smallest and largest possible IDs, so `XRANGE key - +` reads the whole stream. An incomplete ID such as `1526985054069` is completed with the smallest possible sequence number for `<start>` and the largest for `<end>`, which makes it easy to select everything within one millisecond. Prefixing a bound with `(` makes it exclusive, and `COUNT` limits how many entries come back.

Since IDs start with a timestamp, ranges are time queries: pass the milliseconds you care about and you get the entries recorded in that window. Paging works by repeating the call with the last ID you received, made exclusive with `(`. Use [`XREVRANGE`](/redis/commands/streams/xrevrange) to walk the stream backwards.

## Syntax

```redis
XRANGE <key> <start> <end> [COUNT <count>]
```

## Arguments

| Argument | Required | Repeatable | Description |
| --- | --- | --- | --- |
| `<key>` | Yes | No | Redis key targeted by the command. |
| `<start>` | Yes | No | First ID to return; `-` means the smallest possible ID. |
| `<end>` | Yes | No | Last ID to return; `+` means the largest possible ID. |
| `COUNT <count>` | No | No | Maximum number of entries to return. |

## Response

The reply reports the result of the operation. Error replies have the same shape in RESP2 and RESP3 and are surfaced as exceptions by the SDKs below.

| Protocol | Reply |
| --- | --- |
| RESP2 | Array of two-element entry arrays: ID and flat field/value array |
| RESP3 | Array of two-element entry arrays: ID and flat field/value array |

<Note>
  Client libraries often decode bulk strings, maps, sets, and numeric strings into language-native values. The table describes the Redis wire reply.
</Note>

## Examples

TCP examples use the TLS `REDIS_URL` from the Upstash console. REST examples use `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN`.

<Accordion title="go-redis" icon="golang" iconType="brands">

```go
package main

import (
    "context"
    "fmt"
    "os"

    "github.com/redis/go-redis/v9"
)

func main() {
    opts, err := redis.ParseURL(os.Getenv("REDIS_URL"))
    if err != nil {
        panic(err)
    }
    client := redis.NewClient(opts)
    result, err := client.XRange(context.Background(), "my-key", "-", "+").Result()
    if err != nil {
        panic(err)
    }
    fmt.Println(result)
}
```

</Accordion>
