---
title: "CONFIG GET"
description: "Read runtime configuration."
---

Use `CONFIG GET` to read runtime configuration parameters.

Parameter names may contain glob-style patterns, so one call can fetch a family of settings, and the reply is a flat array of alternating names and values in both RESP2 and RESP3.

This deployment exposes only `notify-keyspace-events`, which controls the keyspace notifications published on pub/sub. Other names simply return no matching entries rather than an error, so check the reply for the parameter you asked about instead of assuming it was present.

## Syntax

```redis
CONFIG GET <parameter> [parameter ...]
```

## Arguments

| Argument | Required | Repeatable | Description |
| --- | --- | --- | --- |
| `parameter` | Yes | Yes | One or more glob-style configuration parameter patterns. |

## Important points

- This command can expose administrative information or make a broad destructive change. Restrict it to trusted code paths.
- This deployment exposes only `notify-keyspace-events`. Other patterns return no matching entries.
- Both RESP2 and RESP3 return a flat array of alternating parameter names and values.

## Response

The reply reports the result of the operation. Error replies have the same shape in RESP2 and RESP3 and are surfaced as exceptions by the SDKs below.

| Protocol | Reply |
| --- | --- |
| RESP2 | Flat array of alternating configuration names and values |
| RESP3 | Flat array of alternating configuration names and values |

<Note>
  Client libraries often decode bulk strings, maps, sets, and numeric strings into language-native values. The table describes the Redis wire reply.
</Note>

## Examples

TCP examples use the TLS `REDIS_URL` from the Upstash console. REST examples use `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN`.

<Accordion title="go-redis" icon="golang" iconType="brands">

```go
package main

import (
    "context"
    "fmt"
    "os"

    "github.com/redis/go-redis/v9"
)

func main() {
    opts, err := redis.ParseURL(os.Getenv("REDIS_URL"))
    if err != nil {
        panic(err)
    }
    client := redis.NewClient(opts)
    result, err := client.ConfigGet(context.Background(), "notify-keyspace-events").Result()
    if err != nil {
        panic(err)
    }
    fmt.Println(result)
}
```

<Accordion title="redis-rs" icon="rust" iconType="brands">

```rust
fn main() -> redis::RedisResult<()> {
    let url = std::env::var("REDIS_URL").expect("REDIS_URL is not set");
    let client = redis::Client::open(url)?;
    let mut connection = client.get_connection()?;

    let mut command = redis::cmd("CONFIG");
    command.arg("GET");
    command.arg("notify-keyspace-events");
    let result: redis::Value = command.query(&mut connection)?;
    println!("{result:?}");
    Ok(())
}
```
