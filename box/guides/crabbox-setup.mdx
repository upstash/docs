[Crabbox](https://crabbox.sh) is a CLI tool that runs commands inside a remote box from your local machine. This guide shows how to use it with Upstash Box to run your test suite in a clean cloud environment without touching your local setup.

---

## 1. Install Crabbox

```bash
brew install openclaw/tap/crabbox
```

---

## 2. Get Your API Key

Go to the [Upstash Console](https://console.upstash.com) and create a Box API key. Then export it in your terminal:

```bash
export UPSTASH_BOX_API_KEY=your_api_key_here
```

---

## 3. Warm Up a Box

Create a box with the `warmup` command. This provisions the box ahead of time so it's ready when you need it.

```bash
crabbox warmup --provider upstash-box --upstash-box-runtime node --upstash-box-size small
```

The output includes the box's slug, for example `slug=amber-crayfish-e880d5d3`. Use it to run commands on this box.

You can customize the box to match your project's needs:

| Flag | Description | Values |
|---|---|---|
| `--upstash-box-runtime` | Runtime environment | `node`, `python`, `golang`, `ruby`, `rust` (or `-alpine` variants) |
| `--upstash-box-size` | Box size | `small`, `medium`, `large` |
| `--upstash-box-workdir` | Working directory inside the box | Any path (default: `/workspace/home/crabbox`) |
| `--upstash-box-keep-alive` | Keep the box up and running at all times | `true` / `false` |

---

## 4. Run Your Tests

Run your test command inside the box. Crabbox syncs your working tree into the box, runs the command, and streams the output back.

Use `--env-from-profile` to load variables from a local `.env` file and `--allow-env` to pick which ones to forward. Only the names you allow are sent to the box, and they aren't stored anywhere.

```bash
crabbox run --provider upstash-box --id amber-crayfish-e880d5d3 \
  --env-from-profile .env --allow-env DATABASE_URL,API_KEY -- pnpm test
```

You can use any package manager or test runner:

```bash
# npm
crabbox run --provider upstash-box --id amber-crayfish-e880d5d3 --env-from-profile .env --allow-env DATABASE_URL,API_KEY -- npm test

# bun
crabbox run --provider upstash-box --id amber-crayfish-e880d5d3 --env-from-profile .env --allow-env DATABASE_URL,API_KEY -- bun test
```

<Tip>
Without `--id`, `crabbox run` creates a new box for that run and deletes it when the command finishes. You can skip the warmup step if you don't need to reuse a box.
</Tip>

---

## 5. Stop the Box

A warmed-up box stays up until you stop it:

```bash
crabbox stop --provider upstash-box amber-crayfish-e880d5d3
```

For the full list of commands and options, see the [Upstash Box provider reference](https://crabbox.sh/providers/upstash-box.html).
