This guide hosts [Hermes](https://github.com/NousResearch/hermes-agent) in an Upstash Box and connects [Hermes Desktop](https://hermes-agent.nousresearch.com/docs/user-guide/desktop) on your machine to it over SSH. The agent runs in the box; you chat with it from the desktop app.

---

## 1. Create a Box

Create a keep-alive box with the **Medium** size. See the [quickstart](/box/overall/quickstart) if you haven't created one before.

<Note>
  Hermes is resource-intensive, so we recommend starting with a Medium box to ensure a smooth installation.
</Note>

---

## 2. Connect via SSH

Once the box is running, [set up an SSH key](/box/overall/shell#ssh-keys) and connect to the box from your terminal. You'll use the same key to connect from Hermes Desktop later.

The `box-id` is the name of your box (e.g. `right-flamingo-14486`).

```bash
ssh -i ~/.ssh/upstash_box <box-id>@us-east-1.box.upstash.com
```

---

## 3. Install Hermes

Run the following command to download and install Hermes inside the box.

```bash
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```

Follow the CLI prompts to complete the setup.

---

## 4. Connect from Hermes Desktop

Hermes Desktop connects over SSH with the key from [step 2](#2-connect-via-ssh) and starts Hermes in the box for you.

In Hermes Desktop, go to **Settings → Gateways**, click **Add**, and choose **SSH**. Fill in:

- **Host:** `<box-id>@us-east-1.box.upstash.com`
- **Identity file:** `~/.ssh/upstash_box`

Save the connection and click **Test**. Once it shows **Reachable**, select it to chat with the Hermes running in your box.
