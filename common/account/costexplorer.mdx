title: Cost Explorer
---

The Cost Explorer pages allow you to view your current and previous months’ costs. To access the Cost Explorer, navigate to the left menu and select Account > Cost Explorer. Below is an example report:

<Frame>
  <img src="/img/costexplorer/costexplorer.png" alt="Monthly costs in the Upstash Cost Explorer" />
</Frame>

You can select a specific month to view the cost breakdown for that period. You can also select the product whose costs you want to see: Redis, Vector, QStash, Search, Blob, or Box.

For Redis, Vector, QStash, Search and Blob, the report shows a card per field with the total for the selected product, followed by one row per resource with its cost. Here's the explanation of the fields in the report:

**Request / Commands / Operations:** This represents the total number of requests sent to the resource.

**Storage:** This indicates the average size of the total storage consumed. Upstash database includes a persistence layer for data durability. For example, if you have 1 GB of data in your database throughout the entire month, this value will be 1 GB. Even if your database is empty for the first 29 days of the month and then expands to 30 GB on the last day, this value will still be 1 GB.

**Bandwidth:** This represents the total amount of data transferred for the resource.

**Cost:** This field represents the total cost of the resource in US Dollars.

The Blob tab lists one row per bucket with its operations, average storage, bandwidth, and cost. Buckets that were deleted or transferred to another account during the selected month are marked as such, and their costs still appear in the report.

> The values for the current month is updated hourly, so values can be stale up
> to 1 hour.
