The numbers below reflect current pricing — see the [pricing page](https://upstash.com/pricing/vector) for the most up-to-date information.

## Pay as you go

| Item | Price |
| ---- | ----- |
| Storage | $0.25 / GB per month |
| Operations (queries, upserts, deletes) | $0.40 per 100,000 operations |
| Bandwidth | Free up to 200 GB / month, then $0.03 / GB |

There are no hourly charges for having an index created. A range, query or
fetch is counted as one operation regardless of the number of vectors returned,
while an upsert or delete is counted per vector (a batch upsert of 1000 vectors
is 1000 billable operations).

Storage is the sum of vector, metadata, and data storage. Vector storage is
estimated at 4 bytes per dimension, so it is
`vector count × dimension count × 4 bytes`. Metadata and data are counted by
the average size per vector, up to 48 KB and 1 MB respectively; they have a
soft limit and you will be emailed when an index approaches it.

## Free plan

The free plan is suitable for small projects. It is limited to 10,000 queries
and 10,000 updates per day.

## Limits

| Item | Limit |
| ---- | ----- |
| Maximum dimension | 1536 on the free plan, 3072 on fixed and pay-as-you-go, 5376 on Pro |
| Maximum vector count | Each plan has a vector × dimension cap; 2 billion on pay-as-you-go |
| Metadata size per vector | Up to 48 KB |
| Data size per vector | Up to 1 MB |
| `topK` | Defaults to 10; the maximum number of vectors returned by a query |
| Vector ID | Required and cannot be an empty string |

For batch inserts we recommend an array size of up to 1000 vectors. You can
send either a single vector or an array of vectors to the upsert endpoint.

## Regions

Upstash Vector is currently available in AWS `us-east-1` and AWS `eu-west-1`.
