```go blob.go
bucket, err := blob.NewBucketFromEnv()
```

Building the client is on [Overview](/blob/sdks/go/overview#the-bucket-client). Every method takes a `context.Context` first. Options come as a pointer to a struct; pass `nil` for none.

## Put

```go
func (b *Bucket) Put(
	ctx context.Context, path string, body io.Reader, opts *PutOptions,
) (*CompletedBlob, error)
```

```go reports.go
func saveReport(ctx context.Context, path string) (string, error) {
	f, err := os.Open(path)
	if err != nil {
		return "", err
	}
	defer f.Close()

	b, err := bucket.Put(ctx, "reports/q3.pdf", f, &blob.PutOptions{
		ContentType: "application/pdf",
	})
	if err != nil {
		return "", err
	}
	return b.URL, nil
}
```

Every field is optional. Behaviour and defaults are on [Writing](/blob/bucket/writing#put).

| Field | Type | Description |
| --- | --- | --- |
| `ContentType` | `string` | What the object is stored as. |
| `ContentTypes` | `[]string` | An allow list such as `[]string{"image/*", "application/pdf"}`. A non-nil empty slice is refused with `invalid_content_type_pattern`. See [Constraints](/blob/uploads/constraints#content-types). |
| `MaxSize` | `int64` | Refuses a larger body with `too_large`. Zero is no limit. |
| `Cache` | `string` | The `Cache-Control` this object is stored with. See [Caching](/blob/bucket/caching). |
| `Metadata` | `map[string]string` | Custom key-value pairs. A key with an uppercase letter is refused with `invalid_input` rather than lowercased for you. See [Metadata](/blob/bucket/writing#metadata). |
| `Size` | `int64` | The exact length in bytes, for a reader whose length is not otherwise known. Ignored for a body `Put` can measure. |
| `NoOverwrite` | `bool` | Refuses the write if something is already at the path. See [Conditional writes](/blob/bucket/writing#conditional-writes). |
| `IfUnchanged` | `string` | An etag. The write fails with `conflict` if the object changed since you read it. |
| `Multipart` | `blob.Multipart` | Where a body stops being one PUT. See [Large bodies](/blob/bucket/writing#large-bodies). |

The result is a [`*CompletedBlob`](#records):

```go
body := bytes.NewReader(data)
opts := &blob.PutOptions{ContentType: "image/png"}
b, err := bucket.Put(ctx, "avatars/7.png", body, opts)

b.Path         // "avatars/7.png"
b.URL          // "https://b3f9a2c7d1e4.blob.upstash.io/avatars/7.png"
b.VersionedURL // "...?v=%22d41d8...%22"
b.Size         // bytes stored
b.ETag         // "\"d41d8...\"", what IfUnchanged takes
b.UploadedAt   // time.Time
b.ContentType  // "image/png"
```

### Bodies

```go
bucket.Put(ctx, "notes/1.md", strings.NewReader("# Hello"), nil)

f, err := os.Open("backups/db.tar")
if err != nil {
	return err
}
defer f.Close() // Put reads from its current offset and never closes it
bucket.Put(ctx, "backups/db.tar", f, nil)
```

The body is any `io.Reader`. What `Put` can learn from it decides whether it needs a declared size, and whether a failed request can be sent again:

| Body | Carries its length | Carries a content type | Retried |
| --- | --- | --- | --- |
| `*bytes.Reader`, `*strings.Reader`, `*bytes.Buffer` | Yes | No | Yes |
| A regular `*os.File` | Yes: what is left from its offset | From its extension | Yes |
| Any other `io.ReaderAt` that is also an `io.Seeker`, such as a `multipart.File`, but not a non-regular file | Yes: what is left from its offset | No | Yes |
| Any other `io.Seeker` | Yes | No | No, sent once |
| Any other `io.Reader`, such as a request body, `os.Stdin`, a pipe or a `gzip.Reader` | No: declare `Size` or `MaxSize` | No | Under `MaxSize` yes; under `Size` no |
| `nil` | Zero bytes | No | Yes |

The Retried column is for a single PUT. A body over the [multipart threshold](/blob/uploads/large-files#the-multipart-threshold) goes up in parts, each buffered and retried on its own, whatever the body type, unless the write is conditional.

An explicit `ContentType` wins over the extension. Without either, the object is stored as `application/octet-stream`.

- `Put` never closes the body.
- A `*bytes.Buffer` is read in place, not drained.
- There is no request body type, so `Put` never returns `empty_body`. A zero-length body stores a zero-byte object.

### Request bodies

```go upload.go
func avatar(w http.ResponseWriter, r *http.Request) {
	file, header, err := r.FormFile("file")
	if err != nil {
		http.Error(w, "expected a file", http.StatusBadRequest)
		return
	}
	defer file.Close()

	path := blob.UniquePath("avatars/" + header.Filename)
	b, err := bucket.Put(r.Context(), path, file, &blob.PutOptions{
		ContentType:  header.Header.Get("Content-Type"),
		ContentTypes: []string{"image/*"},
		MaxSize:      5 * blob.MB,
	})
	if err != nil {
		writeError(w, err)
		return
	}
	json.NewEncoder(w).Encode(map[string]string{"url": b.URL})
}
```

A `multipart.File` from `r.FormFile` is measured and read in place. Pass the content type from the form part's header: a `multipart.File` has no name for `Put` to read one from.

A raw request body has no length `Put` can read. Pass `r.ContentLength` as `Size` only when it is known; a chunked request reports `-1`, which is refused:

```go
opts := &blob.PutOptions{
	ContentType: r.Header.Get("Content-Type"),
	MaxSize:     10 * blob.MB,
}
if r.ContentLength > 0 {
	// streamed through; otherwise buffered up to MaxSize
	opts.Size = r.ContentLength
}
b, err := bucket.Put(r.Context(), path, r.Body, opts)
```

The bytes pass through your server here, under your platform's body limit. For anything large, use an [upload handler](/blob/sdks/go/upload-handler) instead. `writeError` is on [Errors](/blob/sdks/go/errors#answering-with-one).

### Streams

```go
// Buffer up to the cap. A reader that runs past it fails with too_large.
bucket.Put(ctx, "export.csv", pr, &blob.PutOptions{MaxSize: 10 * blob.MB})

// Stream straight through, nothing buffered. The declared size must be exact.
bucket.Put(ctx, "export.csv", pr, &blob.PutOptions{Size: 5000})
```

A reader with neither fails with `length_required`. Why is on [Streams and unknown lengths](/blob/bucket/writing#streams-and-unknown-lengths). One that ends short of `Size`, or runs past it, fails with `invalid_input`.

```go
res, err := http.Get(sourceURL)
if err != nil {
	return err
}
defer res.Body.Close()
if res.StatusCode != http.StatusOK || res.ContentLength <= 0 {
	return fmt.Errorf("%s: %s, length %d",
		sourceURL, res.Status, res.ContentLength)
}
opts := &blob.PutOptions{Size: res.ContentLength}
_, err = bucket.Put(ctx, "mirror/video.mp4", res.Body, opts)
```

`res.ContentLength` is `-1` when the length is unknown: a chunked response, or one Go's transport decompressed for you. A negative `Size` is refused with `invalid_input` and a zero one counts as unset, so check it first, or fall back to `MaxSize`.

## UpdateJSON

```go
func UpdateJSON[T any](
	ctx context.Context, b *Bucket, path string,
	fn func(prev *T) (T, error), opts *UpdateJSONOptions,
) (*BlobObject, error)
```

```go
type Settings struct {
	Theme string `json:"theme"`
}

setDark := func(prev *Settings) (Settings, error) {
	next := Settings{}
	if prev != nil {
		next = *prev
	}
	next.Theme = "dark"
	return next, nil
}
opts := &blob.UpdateJSONOptions{
	MaxAttempts: 10,
	Metadata:    map[string]string{"owner": "u7"},
	Cache:       blob.CacheNoStore,
}
_, err := blob.UpdateJSON(ctx, bucket, "u/7.json", setDark, opts)
```

| Field | Type | Description |
| --- | --- | --- |
| `MaxAttempts` | `int` | How many read-transform-write rounds to try before failing with `conflict`. Zero is 6; a negative count is `invalid_input`. |
| `Cache` | `string` | The `Cache-Control` the rewritten object is stored with. |
| `Metadata` | `map[string]string` | Replaces the metadata on the object. Nil keeps it. |

A package function rather than a method, since Go methods cannot take a type parameter. The document is decoded into a `T` with `encoding/json`, and the result encoded the same way. `fn` gets `nil` when nothing is stored, the object is empty, or it holds JSON `null`. An error from `fn` is returned as is, with nothing written. A stored document that is not JSON fails with `invalid_input`.

The loop and its defaults are on [Updating JSON](/blob/bucket/writing#updating-json).

## SignedUploadURL

```go
func (b *Bucket) SignedUploadURL(
	ctx context.Context, path string, opts *SignedUploadURLOptions,
) (*SignedUploadURL, error)
```

```go
up, err := bucket.SignedUploadURL(ctx, "u/7/report.pdf",
	&blob.SignedUploadURLOptions{
		ContentType: "application/pdf",
		Size:        int64(len(data)),
		ExpiresIn:   10 * time.Minute,
	})
if err != nil {
	return err
}

body := bytes.NewReader(data)
req, _ := http.NewRequestWithContext(ctx, http.MethodPut, up.URL, body)
for k, v := range up.Headers {
	if k != "content-length" {
		req.Header.Set(k, v)
	}
}
res, err := http.DefaultClient.Do(req)
if err != nil {
	return err
}
res.Body.Close()
if res.StatusCode != http.StatusOK {
	// a 403 means a header was changed or dropped
	return fmt.Errorf("upload refused: %s", res.Status)
}
```

Returns a `*SignedUploadURL` with `URL string`, `Headers map[string]string` and `ExpiresAt time.Time`. Send `Headers` verbatim, except that `net/http` takes the length from `Request.ContentLength`, not from a header: a `*bytes.Reader` body sets it for you, and an `*os.File` body does not.

| Field | Type | Description |
| --- | --- | --- |
| `ExpiresIn` | `time.Duration` | How long the link should live. Zero is the default. |
| `ContentType` | `string` | The `Content-Type` the upload must send, and what the object is stored as. |
| `Cache` | `string` | The `Cache-Control` the object is stored with. |
| `Metadata` | `map[string]string` | Written as `x-amz-meta-*`, under the same rules as `Put`. |
| `Size` | `int64` | Pins the body's exact length. Zero leaves it open. |
| `NoOverwrite` | `bool` | Refuses the upload if something is already at the path. |

Defaults and lifetimes are on [Signed upload URLs](/blob/bucket/writing#signed-upload-urls).

## Get

```go
func (b *Bucket) Get(ctx context.Context, path string) (*BlobDownload, error)
```

```go
res, err := bucket.Get(ctx, "reports/2026-01.pdf")
if err != nil {
	return err
}
defer res.Body.Close()

res.ContentType // "application/pdf"
res.Size        // 184302
res.ETag        // "\"9f3c...\""
res.Metadata    // map[owner:u7]
io.Copy(w, res.Body)
```

`Body` is the response stream: nothing is buffered, and you must close it. `io.ReadAll(res.Body)` reads it in full.

A missing object fails with `not_found`. It never returns a nil download with a nil error. See [get](/blob/bucket/reading#get).

## List

```go
func (b *Bucket) List(ctx context.Context, opts *ListOptions) (*ListPage, error)
```

```go
var paths []string
cursor := ""

for {
	page, err := bucket.List(ctx, &blob.ListOptions{
		Prefix: "avatars/",
		Limit:  1000,
		Cursor: cursor,
	})
	if err != nil {
		return err
	}
	for _, b := range page.Blobs {
		paths = append(paths, b.Path)
	}
	if page.Cursor == "" {
		break
	}
	cursor = page.Cursor
}
```

Returns a `*ListPage` with `Blobs []BlobObject` and `Cursor string`, which is `""` on the last page.

| Field | Type | Description |
| --- | --- | --- |
| `Prefix` | `string` | Only keys starting with this. |
| `Limit` | `int` | Page size. Zero lets storage pick. |
| `Cursor` | `string` | The `Cursor` from the previous page. |

Defaults and paging are on [list](/blob/bucket/reading#list).

## SignedReadURL

```go
func (b *Bucket) SignedReadURL(
	ctx context.Context, path string, opts *SignedReadURLOptions,
) (*SignedURL, error)
```

```go
link, err := bucket.SignedReadURL(ctx, "reports/2026-01.pdf",
	&blob.SignedReadURLOptions{
		ExpiresIn:  2 * time.Minute,
		DownloadAs: "Report Q3.pdf",
	})

link.URL
link.ExpiresAt // time.Time
```

Returns a `*SignedURL` with `URL string` and `ExpiresAt time.Time`. Cache the link until `ExpiresAt`, never until a deadline you compute from `ExpiresIn`.

| Field | Type | Description |
| --- | --- | --- |
| `ExpiresIn` | `time.Duration` | How long to ask for. Zero is the default. |
| `DownloadAs` | `string` | Save as this filename instead of displaying inline. |
| `ContentType` | `string` | What storage answers with as `Content-Type`, overriding what was stored. |

Defaults and lifetimes are on [Signed read URLs](/blob/bucket/reading#signed-read-urls).

## Delete

```go
func (b *Bucket) Delete(ctx context.Context, path string) error
func (b *Bucket) DeleteMany(ctx context.Context, paths []string) error
func (b *Bucket) DeletePrefix(ctx context.Context, prefix string) error
func (b *Bucket) DeleteAll(ctx context.Context) error
```

```go
// one path
bucket.Delete(ctx, "avatars/me.png")
// a list of paths
bucket.DeleteMany(ctx, []string{"a.png", "b.png", "c.png"})
// everything under a prefix
bucket.DeletePrefix(ctx, "tmp/")
// the whole bucket, on purpose
bucket.DeleteAll(ctx)
```

Each shape is its own method. `DeletePrefix("")` is refused with `invalid_input`; `DeleteAll` is how to say you mean it. `DeleteMany` checks every path before the first request, so a bad path deletes nothing. What each shape does and returns is on [Deleting](/blob/bucket/deleting).

```go
err := bucket.DeleteMany(ctx, paths)
var be *blob.Error
if errors.As(err, &be) && be.Code == blob.CodePartialDelete {
	requeue(be.Failed) // the paths still in the bucket
} else if err != nil {
	return err
}
```

## Multipart cleanup

```go
func (b *Bucket) ListMultipartUploads(
	ctx context.Context, prefix string,
) ([]MultipartUpload, error)

func (b *Bucket) AbortMultipartUpload(
	ctx context.Context, upload MultipartUpload,
) error

func (b *Bucket) AbortStaleMultipartUploads(
	ctx context.Context, olderThan time.Duration, prefix string,
) ([]MultipartUpload, error)
```

```go
uploads, err := bucket.ListMultipartUploads(ctx, "uploads/")
if err != nil {
	return err
}
for _, u := range uploads {
	if err := bucket.AbortMultipartUpload(ctx, u); err != nil {
		return err
	}
}

aborted, err := bucket.AbortStaleMultipartUploads(ctx, 24*time.Hour, "uploads/")
```

`MultipartUpload` is a struct with `Path string`, `UploadID string` and `InitiatedAt time.Time`. Pass `""` as the prefix for the whole bucket.

`AbortMultipartUpload` takes the record, not two strings, because a swapped pair would abort nothing and report success. An empty `UploadID` is refused with `invalid_input`. To abort an upload whose id you stored from an [upload handler](/blob/sdks/go/upload-handler#onuploadcomplete), build the record:

```go
bucket.AbortMultipartUpload(ctx, blob.MultipartUpload{
	Path:     row.Path,
	UploadID: row.MultipartUploadID,
})
```

`olderThan` is the window from [Aborting stale uploads](/blob/bucket/deleting#aborting-stale-uploads). Zero aborts every incomplete upload under the prefix, including ones still running. If an abort fails partway, the uploads already aborted are returned along with the error.

## Records

Records are structs. They nest by embedding, so a `*CompletedBlob` has every `BlobObject` field directly. What each field means is on [Records](/blob/reference/types#records).

| Type | Fields | Returned by |
| --- | --- | --- |
| `BlobObject` | `Path`, `URL`, `VersionedURL`, `Size`, `ETag`, `UploadedAt` | `List`, `Copy`, `Move`, `UpdateJSON` |
| `CompletedBlob` | `BlobObject` plus `ContentType` | `Put`, `OnUploadComplete` |
| `BlobInfo` | `BlobObject` plus `ContentType` and `Metadata` | `Info` |
| `BlobDownload` | `BlobInfo` plus `Body io.ReadCloser` | `Get` |

| Field | Type |
| --- | --- |
| `Path` | `string` |
| `URL` | `string`, `""` on a private bucket |
| `VersionedURL` | `string`, `""` when `URL` is |
| `Size` | `int64` |
| `ETag` | `string` |
| `UploadedAt` | `time.Time` |
| `ContentType` | `string` |
| `Metadata` | `map[string]string` |

Records encode to JSON with the field names the TypeScript SDK uses (`path`, `url`, `versionedUrl`, `uploadedAt`, ...), so one can be returned from your own route as is.
