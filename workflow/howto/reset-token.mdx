---
title: "Reset your QStash Token"
sidebarTitle: "Reset Token"
---

Upstash Workflow uses your QStash token, so resetting the QStash token also
resets the token your workflows use.

You can switch to a new token without downtime: the console gives you a next
token that already works, you update `QSTASH_TOKEN` in your applications, and
then you rotate so the old token stops working.

See [Reset Token](/qstash/howto/reset-token) in the QStash docs for the
step-by-step guide, including the Developer API endpoints.
