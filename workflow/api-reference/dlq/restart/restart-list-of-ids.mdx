---
title: "Multiple IDs"
description: "Restart specific failed Workflow runs by their DLQ IDs."
api: "POST https://qstash-eu-central-1.upstash.io/v2/workflows/dlq/restart"
authMethod: "bearer"
---

Pass one or more `dlqIds` to restart those failed workflow runs from their first steps.

## Query parameters

<ParamField query="dlqIds" type="string[]" required>
  DLQ IDs to restart. Repeat the parameter (`dlqIds=id1&dlqIds=id2`) or pass comma-separated values.
</ParamField>

## Response

<ResponseField name="workflowRuns" type="object[]">Results for the restarted entries. Each includes a new `workflowRunId` and `workflowCreatedAt` in Unix milliseconds. Entries excluded by supplied filters are absent.</ResponseField>
<ResponseField name="cursor" type="string">Empty; this request does not paginate.</ResponseField>

<RequestExample>

```sh curl
curl -X POST 'https://qstash-eu-central-1.upstash.io/v2/workflows/dlq/restart?dlqIds=<DLQ_ID_1>&dlqIds=<DLQ_ID_2>' \
  -H 'Authorization: Bearer <QSTASH_TOKEN>'
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "workflowRuns": [
    { "workflowRunId": "<NEW_RUN_ID_1>", "workflowCreatedAt": 1720000000000 },
    { "workflowRunId": "<NEW_RUN_ID_2>", "workflowCreatedAt": 1720000000000 }
  ],
  "cursor": ""
}
```

</ResponseExample>
