---
title: "Multiple IDs"
description: "Delete specific failed Workflow runs by their DLQ IDs."
api: "DELETE https://qstash-eu-central-1.upstash.io/v2/workflows/dlq"
authMethod: "bearer"
---

Pass one or more `dlqIds` to delete only those DLQ entries.

## Query parameters

<ParamField query="dlqIds" type="string[]" required>
  DLQ IDs to delete. Repeat the parameter (`dlqIds=id1&dlqIds=id2`) or pass comma-separated values.
</ParamField>

## Response

<ResponseField name="deleted" type="integer">Number of DLQ entries deleted.</ResponseField>

<RequestExample>

```sh curl
curl -X DELETE 'https://qstash-eu-central-1.upstash.io/v2/workflows/dlq?dlqIds=<DLQ_ID_1>&dlqIds=<DLQ_ID_2>' \
  -H 'Authorization: Bearer <QSTASH_TOKEN>'
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "deleted": 2
}
```

</ResponseExample>
