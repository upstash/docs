# Upstash Documentation

Source for [upstash.com/docs](https://upstash.com/docs), built and hosted with [Docs7](https://context7.com/docs7).

## Local preview

The [Docs7 CLI](https://context7.com/docs/docs7/cli) needs Node.js 20.19 or newer. From the repo root (where `docs.json` is):

```sh
npx @upstash/docs7 dev
```

The preview runs at `http://localhost:3333` and reloads when you edit files. The first run downloads the renderer and caches it. Use `--port` to change the port and `--host 0.0.0.0` to reach it from another machine or a container. No login is needed.

To install the CLI globally instead:

```sh
npm install -g @upstash/docs7
docs7 dev
```

## Publishing

The site deploys from `main`. Every pull request gets a Docs7 preview link and a broken-link review from the Docs7 bot.

## llms.txt

`llms.txt` and `llms-full.txt` are generated from `docs.json` and the MDX files. Don't edit them by hand. After changing pages, run:

```sh
cd llms && npm install && npm run build
```

CI regenerates them on pull requests if they are stale. See [`llms/README.md`](https://github.com/upstash/docs/blob/main/llms/README.md).
