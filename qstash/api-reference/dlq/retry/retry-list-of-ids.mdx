---
title: "Multiple IDs"
description: "Retry specific QStash DLQ messages by their DLQ IDs."
api: "POST https://qstash-eu-central-1.upstash.io/v2/dlq/retry"
authMethod: "bearer"
---

Pass one or more `dlqIds` to retry only those DLQ entries.

A new message is created for each entry with the original body and headers, then the original entry is removed from the DLQ.


## Query parameters

<ParamField query="dlqIds" type="string[]" required>
  DLQ IDs to retry. Repeat the parameter (`dlqIds=id1&dlqIds=id2`) or pass comma-separated values.
</ParamField>

## Response

<ResponseField name="responses" type="object[]">Publish responses in the same order as the supplied IDs. Each includes a `messageId` and may include `deduplicated`.</ResponseField>
<ResponseField name="cursor" type="string">Empty; this request does not paginate.</ResponseField>

<RequestExample>

```sh curl
curl -X POST 'https://qstash-eu-central-1.upstash.io/v2/dlq/retry?dlqIds=<DLQ_ID_1>&dlqIds=<DLQ_ID_2>' \
  -H 'Authorization: Bearer <QSTASH_TOKEN>' \
  -H 'Upstash-Retries: 0'
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "cursor": "",
  "responses": [
    { "messageId": "<NEW_MESSAGE_ID_1>" },
    { "messageId": "<NEW_MESSAGE_ID_2>" }
  ]
}
```

</ResponseExample>
