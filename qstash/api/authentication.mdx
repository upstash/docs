You'll need to authenticate your requests to access any of the endpoints in the
QStash API. In this guide, we'll look at how authentication works.

## Bearer Token

When making requests to QStash, you will need your `QSTASH_TOKEN` — you will
find it in the [console](https://console.upstash.com/qstash). Here's how to add
the token to the request header using cURL:

```bash
curl https://qstash.upstash.io/v2/publish/... \
  -H "Authorization: Bearer <QSTASH_TOKEN>"
```

## Query Parameter

In environments where setting the header is not possible, you can use the `qstash_token` query parameter instead.

```bash
curl https://qstash.upstash.io/v2/publish/...?qstash_token=<QSTASH_TOKEN>
```

Always keep your token safe and reset it if you suspect it has been compromised.

## Keeping the token secret

`QSTASH_TOKEN` is a secret that can publish messages and modify your resources.
Do not put it in frontend code, a browser bundle, or any environment variable
that ships to the client, since anyone can read it there and use it against your
account.

If your frontend needs to publish a message, call your own backend and let the
backend hold the token. The browser talks to your API, and your API talks to
QStash:

```typescript app/api/publish/route.ts
import { Client } from "@upstash/qstash";

const client = new Client({ token: process.env.QSTASH_TOKEN! });

export async function POST(request: Request) {
  const body = await request.json();

  // Authenticate the caller before publishing. The token is powerful,
  // so only allow requests your application has verified.
  await client.publishJSON({
    url: "https://example.com/process",
    body,
  });

  return Response.json({ ok: true });
}
```

On the backend, guard the route with your own authentication so it cannot be used
as an open proxy, and validate the request body before forwarding it. If a client
only needs to read logs or schedules, give it a [read-only token](/qstash/howto/readonly-token)
instead of the full token. Reset the token from the console if it is exposed; see
[Reset Token](/qstash/howto/reset-token).
